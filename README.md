# RONNY
## אפליקציה לטלפון

RONNY מותקן בטלפון כאפליקציית רשת (PWA), מאותה כתובת של האתר. אין קובץ התקנה נפרד:
- **אנדרואיד (Chrome):** פותחים את האתר בטלפון ולוחצים ״התקנה״ בהודעה שמופיעה למטה, או בתפריט ⋮ ← ״התקנת אפליקציה״.
- **אייפון (Safari):** כפתור השיתוף ← ״הוספה למסך הבית״.

אחרי ההתקנה האפליקציה נפתחת במסך מלא מהאייקון, ועובדת גם בלי קליטה. הטיולים נשמרים בטלפון. מפות הרקע, הניתוב והחיפוש דורשים אינטרנט. אתר הורדות מקשר לכתובת האתר עצמה (עדיף עם ‎`?source=app`‎).

קבצים: `manifest.webmanifest`, `sw.js` (שמירה לעבודה בלי אינטרנט; קבצי האפליקציה נטענים קודם מהרשת), `scripts/install-app.js` (רישום והצעת התקנה בטלפון), `assets/app/` (אייקונים), `_headers` (Netlify).
